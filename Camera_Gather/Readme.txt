Camera Gather Script - Instructions

Requirements:

Install MilestonePSTools
Make sure the MilestonePSTools module is installed. If it is not already installed, use one of the following commands in PowerShell:

For all users:
Install-Module MilestonePSTools

For the current user only:
Install-Module MilestonePSTools -Scope CurrentUser

For more information or manual installation instructions, visit:
https://www.milestonepstools.com/getting-started/#quick-install

Setup:

Add server IPs or hostnames to the Servers.txt file, one per line.

Log into Windows using the Milestone service account that will be used to run the script.

Run the Camera_Gather.ps1 script.
